## 🌌 О проекте Yozora (夜空)

**Yozora** — это полнофункциональное мультимедийное приложение нового поколения, объединяющее каталоги лучших аниме-источников, читалки манги, домашний медиа-сервер и стриминг в единый интерфейс с неоновой эстетикой Midnight.

Больше не нужно терпеть навязчивую рекламу, всплывающие окна и битые видеоплееры: Yozora напрямую извлекает видеопотоки, парсит озвучки, предоставляет встроенный веб-плеер, синхронизирует списки с трекерами и вещает видео на любые домашние устройства.

## ✨ Ключевые возможности

### 🎬 1. Ультимативный Аниме-Плеер & Каталог
* **Мульти-источниковая карточка**: Автоматический кросс-поиск тайтла по базам *AniLibria, AnimeGo, Jut.su, YummyAnime, AniLib* с интеллектуальным алгоритмом сопоставления названий.
* **Выбор озвучек и качества**: Мгновенное переключение студий дубляжа (AniLibria, Studio Band, Dream Cast, SHIZA Project, Дубляж и др.) и качества (1080p, 720p, 480p, 360p).
* **Встроенный HLS/HTML5 плеер & интеграция с MPV/VLC**: Просмотр прямо в окне приложения или запуск во внешнем плеере одной кнопкой.
* **⚡ AniSkip Auto-Skip**: Автоматический пропуск опенингов без необходимости отвлекаться на экран.
* **Таймер сна (Sleep Timer)**: Автовыключение воспроизведения через 15, 30, 45, 60 минут или после окончания серии.
* **Чистые скриншоты**: Моментальный снимок кадра в оригинальном разрешении без элементов интерфейса в буфер обмена.

### 🎧 2. Обработка звука (Audio DSP) & Видео-шейдеры
* **🌙 Ночной режим (Night Mode)**: Динамическая компрессия звука — приглушение громких спецэффектов/взрывов и выравнивание тихой речи.
* **🗣️ Voice Clarity**: Усиление разборчивости голосов персонажей (+4.5 dB на частоте 2.4 кГц).
* **⏱️ Audio Offset $\pm$ 2000 мс**: Точная ручная подгонка задержки звуковой дорожки для устранения рассинхрона.
* **🗡️ Видео-фильтры**: Шейдеры *Anime Crisp (CAS)*, *Vibrant Color*, *HDR Boost*, *Soft Night*.

### 📖 3. Читалка манги (Manga Reader Pro)
* **Интеграция с MangaDex и Remanga**: Огромный каталог манги, манхвы и маньхуа на русском языке.
* **Режимы чтения**:
  * 📜 **Webtoon**: Бесконечная вертикальная лента с плавной прокруткой.
  * 📖 **Постраничный режим**: Перелистывание клавишами, свайпами и кликами.
  * 📚 **Две страницы (Double Page Spread)**: Объединение смежных страниц для комфортного чтения книжных разворотов.
* **✂️ Smart Margin Crop**: Умная автоматическая обрезка пустых полей сканов.
* **💡 Комфортные фильтры**: Сепия, Ночной режим, Ч/Б и тёплый свет.
* **📥 Офлайн-загрузка глав**: Сохранение глав для чтения без интернета.

### 🏠 4. Домашний медиа-сервер & Smart TV (DLNA / UPnP)
* **Встроенный DLNA-сервер**: Автоматическое SSDP-обнаружение в локальной сети (`239.255.255.250:1900`).
* **Вещание на любые Smart TV**: Трансляция видео и загрузок на Samsung Tizen, LG webOS, Android TV, Apple TV (VLC), Kodi и медиа-приставки без установки приложений на ТВ.
* **🐳 Headless Server Mode**: Запуск сервера без GUI (`-server`, `-headless`) для NAS, Docker, VPS или Raspberry Pi.
* **📺 10-Foot UI & D-Pad навигация**: Специальный крупный интерфейс для экранов телевизоров с полной поддержкой клавиатуры, геймпада и пультов.
* **📱 Виртуальный пульт / QR-подключение**: Управление воспроизведением с экрана смартфона.

### 💬 5. Социальные фичи & Комьюнити
* **🗨️ Летящие комментарии (Данмаку / Danmaku)**: Бегущие комментарии зрителей поверх видео в стиле Bilibili и Niconico с выбором цветов текста.
* **📚 Пользовательские коллекции (Подборки)**: Создание тематических списков с уникальными иконками, шеринг и импорт подборок через Base64-код.
* **🎮 Discord Rich Presence**: Нативный статус в профиле Discord с отображением тайтла, номера серии, времени и кнопки «Смотреть в Yozora».

### 📊 6. Профиль, Трекеры & Геймификация
* **Синхронизация с Shikimori, AniList и MyAnimeList**: Статусы («Смотрю», «В планах», «Просмотрено»), оценки и списки.
* **📅 Интерактивное расписание онгоингов**: Календарь выхода новых серий по дням недели и уведомления.
* **🏅 12 Достижений**: Разблокируемые награды («Легенда Отаку», «Марафонец», «Ночной дозор», «Книжный червь» и др.).
* **Инфографика**: Круговая диаграмма любимых жанров, счетчик просмотренных часов и серий.
* **📻 Аниме-радио**: Фоновое радио со станциями *Anison.FM, Gensokyo Radio, Lofi Anime, J-Pop Hits*.
* **🧲 Торрент-стриминг**: Поиск раздач AniLibria, копирование Magnet-ссылок и загрузка `.torrent`.

## 🚀 Установка и запуск

### Вариант 1: Готовые сборки
Скачайте актуальный релиз для вашей операционной системы со страницы **[Releases](https://github.com/Erridian/anicli-gui/releases)**:
* **Windows**: `anicli-ru-gui.exe`
* **Android**: `anicli-gui-android.apk`
* **Linux / macOS**: Бинарные сборки `x86_64` и `arm64`

### Вариант 2: Сборка из исходников (Go)
Требуется установленный **Go 1.22+**:
```bash
# Клонирование репозитория
git clone https://github.com/Erridian/anicli-gui.git
cd anicli-gui

# Сборка графического приложения
go build -v ./cmd/anicli-ru-gui

# Запуск
./anicli-ru-gui
```

## ⚙️ Флаги запуска

```text
Использование: anicli-ru-gui [параметры]

Параметры:
  -p, --port <порт>      Порт локального веб-сервера GUI (по умолчанию: 3998)
  -s, --server           Режим фонового медиа-сервера без открытия окна браузера
  --headless             Аналог -server (для NAS, Docker, VPS, микрокомпьютеров)
  -c, --cli              Запуск классического CLI-режима в терминале
  --check-providers      Проверить статус доступности зеркал и провайдеров
  -h, --help             Показать справку по командам
```

## ⌨️ Горячие клавиши (Горячие кнопки)

| Клавиша | Действие |
| :--- | :--- |
| `Пробел` / `k` | Пауза / Воспроизведение |
| `←` / `→` | Перемотка назад / вперед на 5 секунд |
| `J` / `L` | Перемотка назад / вперед на 10 секунд (или двойной тап по краям на тачскрине) |
| `↑` / `↓` | Увеличение / уменьшение громкости |
| `F` | Полноэкранный режим |
| `M` | Включение / отключение звука (Mute) |
| `S` | Сделать чистый снимок кадра (Screenshot) |
| `N` | Переход к следующей серии |
| `Esc` | Закрыть модальное окно / читалку / плеер |
| `A` / `D` (Манга) | Предыдущая / следующая страница |
